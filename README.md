# SA+ — Sistema de Avaliações

Projeto frontend base para um **Sistema de Avaliações Escolar (SA+)**, construído com HTML, CSS e JavaScript modular.

---

## 🚀 Visão Geral

O SA+ é um projeto de estudo e prática de arquitetura frontend moderna, com foco em:

* Organização escalável de CSS (estrutura modular)
* JavaScript modular (ES Modules)
* Base de interface limpa e sem dependências de frameworks pesados
* Estrutura pronta para crescimento (componentização)

---

## 📁 Estrutura do Projeto

```
css/
  base/          # Reset e estilos base
  components/    # Componentes reutilizáveis (botões, navbar, cards...)
  sections/      # Seções específicas de páginas
  layout.css     # Estrutura geral
  main.css       # Import principal
  responsive.css # Responsividade
  variables.css  # Variáveis globais

js/
  main.js
  module/
    navbar/
      collapse.js
      header-scroll.js
      scrollspy.js

assets/
  icons/
    favicon.ico
    logo.svg
```

---

## 🧠 Conceitos Aplicados

* Arquitetura CSS modular (inspirado em ITCSS)
* Componentização de estilos
* JavaScript com ES Modules
* Separação de responsabilidades
* Base escalável para SPA ou multipage

---

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript (ES Modules)
* Bootstrap (CDN opcional para layout/base UI)
